# scoop-bucket

Scoop bucket for paxel's tools on Windows. Manifests install prebuilt binaries
from each tool's GitHub release; every release workflow pushes its own manifest
here, so `scoop update` follows new versions.

```powershell
scoop bucket add paxel https://github.com/paxel/scoop-bucket
```

| Tool | Install | What it is |
|------|---------|------------|
| [dedup](https://github.com/paxel/dedup-rs) | `scoop install dedup` | Forensic data-inheritance triage: dedupe, diff and browse file piles (CLI + desktop app) |
| [whiteboxed](https://github.com/paxel/whiteboxed) | `scoop install whiteboxed` | WYSIWYG editor for arc42 building-block views |
| [wiptracker](https://github.com/paxel/wipTracker) | `scoop install wiptracker` | One-line always-on-top bar showing the task you are focused on right now |
| [catlog](https://github.com/paxel/cat-a-log) | `scoop install catlog` | Local-first catalog for foster cats, no server, no account |

Not in this bucket: [claude-here](https://github.com/paxel/claude-here). It has
no Windows build; on Windows it runs inside WSL2, installed in the distro with
Linuxbrew (`brew tap paxel/tap && brew install claude-here`) or the release
`install.sh`. See its README for the WSL notes.

For macOS and Linux see [homebrew-tap](https://github.com/paxel/homebrew-tap).

Everything here is generated by the release workflows of the tool repositories;
do not edit the manifests by hand.
